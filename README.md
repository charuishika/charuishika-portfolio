# Charuishika Portfolio

A modern personal portfolio website showcasing my projects, technical skills, achievements, education, and experience as a Computer Science Engineering student at SASTRA Deemed University.

## Live Website

🔗 https://charuishika-portfolio.vercel.app

## About

This portfolio highlights my journey as a Full Stack Developer and AI Enthusiast, featuring academic achievements, internships, certifications, and software development projects.

## Features

* Responsive design for desktop and mobile devices
* Dark/Light theme toggle
* Interactive project showcase
* Technical skills section
* Internship and experience timeline
* Achievements and certifications
* Education details
* Resume download option
* Contact section with social links

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
